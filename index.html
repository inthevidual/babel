      How it works

      The right-hand document starts as an exact copy of the original. Type over the text paragraph by paragraph. Paragraphs can’t be split or merged and images, footnote references and fields stay where they are, so the translated file keeps the original’s structure and styles exactly.

      A bar in the left margin marks paragraphs you have changed (blue) or confirmed as done (green). A page that no longer fits gets a red edge and a note saying by how much.

      Clicking an underlined word shows the suggestion. Character counts include spaces and cover the body text, footnotes and endnotes, like Word’s count.

      Your work is saved in this browser as you type. Versions lets you go back to any earlier state.
